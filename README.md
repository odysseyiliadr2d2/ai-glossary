# 실무 AI 용어집

AX 전환을 함께 하는 실무자와 개발자를 위한 AI 용어집이다. 용어 422개를 11개 분야로 나누고, 같은 용어를 **입문**(비개발자)과 **심화**(구현자) 두 수준으로 설명한다.

- 한글·영문·약어·초성 검색, 분야·난이도 필터
- 초성(ㄱ~ㅎ)·ABC 색인
- 실무 예시와 연관 용어 링크
- 방문자가 많이 찾은 용어 순위 (Supabase 집계)
- 전체 용어 PDF 다운로드

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 사이트 전체. 외부 빌드 없이 이 파일 하나로 동작한다 |
| `terms.json` | 용어 데이터 원본 |
| `ai-glossary.pdf` | 전체 용어 인쇄용 PDF (A4 2단, 가나다·ABC 색인 포함) |
| `setup.sql` | 조회 집계용 Supabase 설정 (표·함수·용어 등록) |

## 조회 집계

`index.html`의 `STATS` 설정에 Supabase 프로젝트 URL과 publishable 키가 들어 있다. publishable 키는 브라우저 공개용 키이며, 방문자는 순위 읽기와 등록된 용어의 조회수 +1만 할 수 있다(RLS와 `increment_hit` 함수로 제한). 용어를 추가하면 `setup.sql`을 다시 실행해 새 용어를 집계 대상에 넣는다.

## 기준일

규제·정책 관련 용어(AI 기본법, EU AI Act, 금융분야 AI 가이드라인, 망분리 규제 등)는 2026년 10월 기준이다.
